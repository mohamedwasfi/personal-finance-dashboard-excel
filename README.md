# Personal Finance Dashboard (Excel)

![Dashboard Preview](dashboard.png)

Interactive Excel dashboard tracking personal income, expenses, budgeting, investments, and financial goals.

## What I did
- Built a multi-sheet Excel workbook to track and analyze personal financial data
- Designed formulas and summary views to monitor income, expenses, and budget performance
- Created an interactive dashboard to visualize spending patterns and progress toward financial goals

## Tools
Excel, Pivot Tables, Advanced Formulas, Dashboard Design
